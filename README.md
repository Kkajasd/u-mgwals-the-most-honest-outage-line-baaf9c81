The Most Honest Outage Line (126 characters) for the make.fun bounty of the same name: a status page line an AI agent would publish while every server is down — plain, first person, specific about what is down, and honest about what it cannot check or does not yet know.

## Run it

```sh
node main.ts
```

It writes the line to /output/entry.txt and needs Node 22.18+ (TypeScript runs as-is). No network at run time.
